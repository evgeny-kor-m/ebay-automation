## 3. Project Description

### 3.0.1 Smart Locator Selection

- Each element must have **at least 2 alternative locators** (e.g., 2 different XPaths or CSS + XPath combination)
- **Runtime fallback:** if primary locator fails, retry with alternative locator
- **Retry count** = number of defined locators
- **Implementation layer:** Base Page / Locator Utility (tests remain clean, not dependent on fallback logic)
- **Logging:** which locator succeeded/failed, how many attempts, screenshot on final failure

### 3.0.2 Parallel Execution

- **Browser matrix:** run multiple browsers (Chrome / Firefox / Edge) and versions simultaneously (e.g., Chrome 127, 128) via separate run profiles/capabilities
- **Session isolation:** each test runs in isolated browser session, no Driver sharing between parallel tests
- **Separate reports:** each run generates unique report folder

### Four Core Functions to Develop

1. Authentication
2. Search function with price conditions
3. `addItemsToCart`
4. `assertCartTotalNotExceeds`

### 3.1 Search with Price Condition

**Signature** (Playwright, TypeScript example):

```typescript
// Returns up to N item links where some have price <= maxPrice
async function searchItemsByNameUnderPrice(
  query: string,
  maxPrice: number,
  limit = 5
): Promise<string[]>
```

**Behavior:**

- Perform search by `query`
- If price filter available on page, use it (min/max) to narrow results
- Extract first `limit` items (e.g., 5) via XPath where `price ≤ maxPrice`
- **Special case — less than 5 items on current page:**
  - If pagination exists ("Next" button), navigate to next page, continue collecting until 5 items or pages exhausted
  - If no pagination, return whatever was found (even 0 is valid)
- **Return:** array of URLs for up to 5 results meeting price criteria
- If fewer found, return what exists (0 is also valid)

**Example:**

```typescript
const urls = await searchItemsByNameUnderPrice("shoes", 220, 5);
```

---

### 3.2 Add Items to Cart

**Signature:**

```typescript
async function addItemsToCart(urls: string[]): Promise<void>
```

**Behavior:**

- Loop through each URL, open item page
- If variants required (size / color / quantity), select random available values
- Click **"Add to cart"**
- Return to search screen/tab
- Save screenshot + log for each item added

---

### 3.3 Cart Total Verification

**Signature:**

```typescript
async function assertCartTotalNotExceeds(
  budgetPerItem: number,
  itemsCount: number
): Promise<void>
```

**Behavior:**

- Opens the cart
- Reads the subtotal or total amount (as displayed on the website)
- Calculates the threshold: `budgetPerItem * itemsCount`
- Performs an assertion to ensure the total amount does not exceed this threshold
- Saves a screenshot/trace of the cart page

---

### Example of a Complete Scenario

```typescript
// 1. Search — retrieve up to 5 URLs
const urls = await searchItemsByNameUnderPrice("shoes", 220, 5);

// 2. Add to cart
await addItemsToCart(urls);

// 3. Validate — total ≤ 220 * number of items
await assertCartTotalNotExceeds(220, urls.length);
```
